Polaris — Orchestrated Research

Telegram webhook → Eve orchestrator → four specialist subagents sharing a Redis scratchpad, delivering live-edited replies.

Flow

Telegram → Live edit

  • POST /eve/v1/telegram verified by secret
  • turn.started posts ⏳, actions.requested edits 🔍/🗺️/📊/✍️
  • message.completed edits same message to answer

Delegation

Orchestrator pattern

Planner first → researcher + analyst parallel → writer synthesis. Each subagent is an Eve tool with fresh history; scratchpad carries state.

Durability

Sessions + Memory

  • chat_id + message_thread_id → durable session
  • Redis scratchpad recalled at turn.started
  • Survives deploys, shareable across subagents
